# <u>RogTextAdventure</u>

## What Is It

**Remit:**
Create a simple 80s style text adventure that runs in a console, then translate it into as many console supporting languages as possible to show my flexibility and knowledge
of programming languages.

**Will Be Writen In:**
- VB .Net
- C#
- Delphi
- COBOL (!!)

There is a JavaScript version which technically breaks the remit as it has sound and visual effects, but I thought why not see what it would look like as a web page!

As a tech demo it is currently limited to movement only via simple commands such as: move north

Really needs some sort of NLP to create a better parser!
