# <u>RogTkinter IDE</u>

**What It Does**

Experiment to see if I could create an IDE for creating TKInter projects.
There are a few web based editors but they are a bit hit and miss..
This is still; in development and there a few issues to iron out before I can confidentally say every
widget can be added and works properly!

**Features:**
- user defined names for each widget, that is name of variable to assign to the widget creation e.g. LBLEnterName
- drag-n-drop interface
- widget properties can be set in the GUI
- creates commented Python file with all imports etc
