# <u>RogStock</u>

## What It Is

**Simple ISO9001 style stock system written in C#**

Still in development, purposely posted on GITHub early so people can follow the development of the project via the branches, with the latest branch being the latest version of the project

**Features Include:**
- Uses SQL Server Reporting Services for reports
- SQL Server backend
- custom user colour scheme!
- Location/Lot tracking
- UOM
- Product families
- Location renaming
- transaction logging

**Folders**
- RogStock2025Suite the original version
- RogStock2026Suite the latest more advanced version


**Why Include The 2025 Version?**
Easy, to show where the project started and how it was developed. 
It was during this process the RogEngine was born and triggered the cease of developing the 2025 version and the rise of the 2026!

The 2026 version uses the RogEngine for mainmenu/security and more!

Also the applications use custom titlebars!
